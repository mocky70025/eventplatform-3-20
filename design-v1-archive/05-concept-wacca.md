# PHASE 3.2 コンセプトシート：Wacca（統合版）

ブレストで出た有望案を、5W1H と コンセプトシートで「ひと言で言える」コンセプトに圧縮する。
organizer / store は**一つのブランド・一つのコンセプト・テーマカラーだけ差別化**の方針なので、コンセプトは統合版で1本。

---

## 5W1H シート（Wacca全体）

| 項目 | 内容 |
|---|---|
| **Who（誰が）** | 地域中小イベントの**個人〜小規模主催者**（年4〜12回開催、月収副業レベル〜本業の片手間）と、**個人〜小規模出店者**（キッチンカー、屋台、クラフト、副業〜小規模本業） |
| **What（何を）** | お互いを**写真と物語で見つけ合い**、申請〜書類〜お金〜当日連絡まで**一画面で完結**する、両側マッチングプラットフォーム |
| **When（いつ）** | 主催者：イベント企画開始〜事後精算（約1.5ヶ月）<br>出店者：次の出店先探し〜出店終了（2〜4週間） |
| **Where（どこで）** | **スマホ完結**（副業時間・移動中・スキマ時間に動ける） |
| **Why（なぜ）** | 既存代替（LINEグループ／Instagram DM／Excel／モビマル）は、**規模が合わない**か**散在しすぎ**か**業務システム的で世界観が合わない**。地域のお祭り・マルシェ文化を支える「個人〜小規模の輪」を、楽しさを失わずデジタル化する |
| **How（どうやって）** | **写真主体プロフィール／双方向レビュー／一画面集約ダッシュボード／テンプレ＋書類使い回し／お祭りモチーフUI**の組み合わせで、業務システム的にならない「お祭りの賑わいと信頼の両立」を実現 |

## コンセプトシート

### タイトル

**Wacca（ワッカ）**

### キャッチコピー候補（3案）

| # | コピー | 狙い |
|---|---|---|
| 1 | **「出会いが、お祭りになる。」** | 出会い＝祭りの始まり。両側マッチングと楽しさを直結 |
| 2 | **「次の輪を、ひと画面で。」** | 「輪」というブランドと「一画面集約」を直結 |
| 3 | **「お祭りを、続けていく人たちへ。」** | 地域の祭り文化を支える人への共感メッセージ |

**推奨：#1「出会いが、お祭りになる。」**
- 主催者にも出店者にも刺さる（両側性）
- 「お祭り」がトーン（賑わい・楽しさ）を伝える
- 「出会い」が機能（マッチング）を伝える
- 10文字でリズミカル

### サービス概要（3行）

> Waccaは、地域のお祭り・マルシェを支える主催者と出店者が、写真と物語でお互いを見つけ合うためのプラットフォームです。応募管理・書類・お金・当日連絡まで、ひと画面で完結します。賑わいの中にも、安心してビジネスができる「輪」をつくります。

### 提供する3つの価値

| # | 価値 | 主催者にとって | 出店者にとって |
|---|---|---|---|
| 1 | **世界観で出会える** | 写真とタグで「うちのマルシェに合う出店者」がすぐ見つかる | 雰囲気・客層・主催者の世界観が事前に分かる |
| 2 | **ひと画面で完結する** | 申請受付〜書類〜入金〜当日連絡まで散らばらない | 案件探し〜申請〜書類〜出店後フォローまでスマホ1台 |
| 3 | **賑わいの中の信頼** | 出店者の過去レビュー・履歴が見えて、初対面でも安心 | 主催者の支払い実績・集客実績・評判が見えて、空振りを避けられる |

## ブランドトーン

### Waccaの「人格」

> **「地元のお祭りを毎年仕切ってる、デザイン感度の高い30代の頼れる先輩」**
> — 業界の人を皆知ってる。優しいけど甘くない。礼儀は大事。デザインは譲らない。

### キーワード（5つ）

1. **温かい**（賑わい・人の気配）
2. **頼れる**（信頼・安心の根拠）
3. **整っている**（散らかってない、シンプル）
4. **小さく回る**（個人・小規模・身の丈）
5. **楽しい**（業務ではなくお祭り）

### トーンの対比（◯印が方向性）

| 軸 | ← | 中央 | → |
|---|---|---|---|
| プロフェッショナル | | | ◯ フレンドリー |
| シンプル | ◯ | | にぎやか *(中身は整然、装飾でお祭り感)* |
| 都会的 | | | ◯ 地域密着 |
| 落ち着いた | | ◯ | エネルギッシュ |
| 新しい | | | ◯ 親しみのある |

→ 既存方針（Cookpad的な温かみ）と整合。

| 軸 | organizer | store |
|---|---|---|

| ホームの主役要素 | 「次のお祭りまであと◯日」「申請◯件、要対応◯件」 | 「今週末の◯件、あなた向け」「気になる◯件」 |
| アイコンモチーフ | 提灯・暖簾・神輿 | 屋台・お盆・のれん旗 |

## ミッション（既存DESIGN.mdの「ブランドストーリー」を継承・具体化）

> **地域のお祭り・マルシェ文化を、楽しさを失わずデジタル化する。**
> 個人〜小規模の主催者と出店者の「輪」を、写真と信頼でつなぐ。

## 三方良し

### ユーザーにとって
- **主催者**：未知の出店者と安心して出会え、煩雑な事務から解放される。世界観に馴染むツール
- **出店者**：次の現場が労力少なく決まる。現地で後悔せず、自分の世界観で正しく見つけてもらえる

### ビジネスにとって
- **収益**：出店料の決済手数料 + プラン（無料/有料）
  - 無料：月1イベントまで／応募管理機能
  - 有料：月1,000〜3,000円程度／無制限＋自動化機能
- **成長**：地域単位でロールアウト（最初は1都市の主催者コミュニティから）

### 私たち（チーム）にとって
- 地域文化を残す側に立てる
- 「業務システム」ではなく「楽しいプロダクト」を作れる
- デザイン・テクノロジーで地域貢献
