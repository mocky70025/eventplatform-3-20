# PHASE 1b 競合・代替手段の調査（机上叩き台）

主催者・出店者がそれぞれ「Waccaが解こうとしている課題」を**現状どうやって解決しているか**を整理する。実ユーザーリサーチができないため、机上知識ベースで作成し、後日確認が必要な項目は `[要確認]` と明記。

---

## 1. 主催者側の代替手段（イベント主催者がキッチンカー・屋台を集める方法）

| 手段 | 内容 | 強み | 弱み |
|---|---|---|---|
| **モビマル（mobimaru）** | キッチンカー業界最大手のマッチングプラットフォーム。出店者DB保有、主催者からの出店募集も対応 [要確認: 詳細料金体系] | 出店者母数が多い、業界標準として認知 | 手数料・利用料が発生、UIが業者向け |
| **LINEグループ・知人紹介** | 地域の主催者ネットワーク内で出店者を回す | コストゼロ、信頼ベース | スケールしない、知り合いの知り合いまで |
| **ケータリング会社への一括依頼** | 出店者の手配を業者に丸投げ | 楽、品質保証 | コスト高、業者の取り分大、選択肢が狭い |
| **Instagram DM・SNS個別募集** | 主催者がSNSで出店者を直接スカウト | 無料、機動的 | 連絡漏れ、契約管理が個別チャット、トラブル時の証跡なし |
| **イベント告知サービス（Peatix, PassMarket等）** | 一般客向けの集客サービスを兼用 | 集客と一体化 | 出店者マッチング機能はない、本来用途違い |
| **地域コミュニティ掲示板・自治体窓口** | 商工会・自治体が出店者リストを保有 | 公的信頼感 | 古い、デジタル化されていない |
| **過去の出店者リストの再利用** | 自前のExcel管理 | 既存関係を活かせる | 新規開拓不可、属人化 |

### 主催者側の主要痛み（推定）

1. **集めるのが大変**：新規イベントで必要な業種・規模の出店者を毎回ゼロから探す
2. **やりとりが煩雑**：申請者ごとにメール／LINE／電話がバラバラ
3. **契約・書類管理**：営業許可証・保険・出店料の入金確認が紙やExcel
4. **当日の運営**：誰がいつ来るか、レイアウトをどう組むか
5. **質の見極め**：初対面の出店者が信頼できるか判断できない

## 2. 出店者側の代替手段（キッチンカー・屋台が出店先を探す方法）

| 手段 | 内容 | 強み | 弱み |
|---|---|---|---|
| **モビマル** | 出店者として登録、案件を受ける | 案件量、業界標準 | 競争激しい、手数料、優良案件は固定業者に流れがち [要確認] |
| **SHOPCOUNTER** | ポップアップショップ向けスペースマッチング [要確認: キッチンカー対応度] | 商業施設の案件 | キッチンカー特化ではない |
| **オフィスランチ系（メロウ／Mellow 等）** | オフィス街への定期出店マッチング | 安定収益 | 都心限定、平日ランチのみ |
| **Instagram / Twitter** | 主催者を自分から見つける、フォロワー経由で声がかかる | 顔出しで信頼構築可 | 営業に時間取られる、運頼み |
| **業界知人ネットワーク（口コミ）** | 先輩キッチンカーから紹介 | 即戦力、信頼 | 新規参入者は入れない |
| **自治体・道路占用許可サイト** | 公的イベント・公園出店募集 | 集客見込める | 募集が散在、応募が面倒 |
| **出店者向けLINEオープンチャット** | 業界内で案件共有 | 即時性 | 早い者勝ち、信頼性まちまち |

### 出店者側の主要痛み（推定）

1. **次の現場が決まらない不安**：毎週「来週どこ行くか」を探す
2. **応募・契約が属人化**：主催者ごとにフォーマット違う、書類重複提出
3. **条件が見えない**：出店料・売上見込み・客層が事前に分からない
4. **キャンセル・トラブル対応**：当日キャンセルや支払いトラブル時に立場が弱い
5. **収益管理**：出店ごとの利益・経費・距離を自分でExcel管理

## 3. Waccaの立ち位置（差別化仮説）

既存代替の弱みから、Waccaが**勝てる可能性のあるポジション**：

| 軸 | 既存の典型 | Waccaの可能性 |
|---|---|---|
| **対象規模** | モビマル等は大手・全国 | **地域密着の中小イベント主催者**（自治会、商店街、寺社、小規模商業施設）に強くなれる |
| **やりとり** | LINE/メール/紙の混在 | **申請〜書類〜決済まで一画面**で完結 |
| **書類** | 都度PDF送付・確認 | **営業許可証のAI自動読み取り**（既存機能）で再利用 |
| **信頼性** | 顔の見えない初対面 | **レビュー・履歴・写真**で双方向の信頼可視化 |
| **トーン** | 業務システム的・無機質 | **Cookpad風の温かみ**で「お祭り」の雰囲気を担保 |

→ **Waccaが本気で勝てる仮説**：
> **「地域の中小イベント × 個人〜小規模キッチンカー」**の領域で、
> **LINE/メール混在の煩雑さを「一画面で完結」に変える**プラットフォーム。
> 業務システムではなく**「お祭りの楽しさ」を残したUI**で、両者にとって**最初のWeb化体験**になる。

## 4. 機会領域（Opportunity Map）

```
                  業務向け
                     ▲
                     │  [モビマル：大手・全国]
                     │
                     │
  業界特化 ◄────────┼────────► 一般・汎用
                     │           [Peatix、SHOPCOUNTER]
                     │
                     │
  ★[Wacca候補：     │
   地域密着×温かみ] │
                     ▼
                  カジュアル
```

**狙うべき空白**：「業界特化 × カジュアル × 地域密着」の象限。
ここは大手も小手も埋めていない領域で、ローンチ前の弱者が勝てる可能性がある。
