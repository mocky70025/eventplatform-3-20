# PHASE 3.1 ブレインストーミング（organizer / store）

PHASE 2 の優先課題に対して、教科書のブレスト4原則（批判厳禁／自由奔放／質より量／結合改善）でアイデアを発散→KJ法で収束。

---

## 3.1.A organizer 側ブレスト

### 解くべき課題（再掲）
1. 応募管理ツール散在 → 一画面集約
2. 出店者の世界観・履歴が見えない → 視覚的判断
3. 個別メール送付・入金確認漏れ → 一斉連絡・自動化

### 発散：35案

**A. 一画面集約系**
1. ダッシュボードに「今やるべきこと」だけ並ぶ
2. 申請一覧をInstagram風の写真グリッドで
3. ステータスごとに色分けカード（新規/レビュー中/承認済み/却下）
4. ドラッグ&ドロップで申請を承認/却下/保留に振り分け
5. 申請を「お気に入り」「気になる」マークでブックマーク
6. 募集ページのURLをコピーしてSNSにそのまま貼れる
7. 申請ステータスを期日でカウントダウン表示
8. 当日の主催者TODOリストが自動生成

**B. 視覚的判断系**
9. 出店者プロフィールがInstagram的な9枚グリッドで表示
10. 過去出店イベントの主催者レビューが星＋写真で並ぶ
11. 「世界観タグ」で出店者を絞り込み（ナチュラル/モダン/レトロ等）
12. 出店者ごとに「料理ビジュアル」スライドショー
13. 過去出店時の現場写真をワンクリックで見られる
14. 出店者の「営業中の様子」動画自動取り込み
15. AIによる「あなたのマルシェに合う出店者」レコメンド
16. 主催者同士の「あの人良かったよ」共有機能

**C. 連絡・自動化系**
17. 申請者全員に一斉メッセージ送信（テンプレあり）
18. 個別メッセージは記録が残るチャット形式
19. 出店者から提出された営業許可証をOCRで自動チェック
20. 出店料の入金状況をリアルタイムで色変化（赤→黄→緑）
21. 入金未確認の出店者に自動リマインド
22. 当日の集合時刻・場所を承認者全員に自動送信
23. 募集締切前日に自動アラート
24. Stripeでの出店料一括集金
25. キャンセル時の補欠繰り上げ自動通知

**D. 軽やか・モバイル系**
26. スマホでも完全機能のレスポンシブ
27. PWAでホーム画面追加可能、通知も来る
28. 申請レビューが30秒で終わる「Tinder的UX」
29. 一覧画面で長押しで操作メニュー
30. 朝のスキマ時間用「3分でできる作業」リスト

**E. 楽しさ・世界観系**
31. 主催者のロゴ・テーマカラーで管理画面が着色される
32. イベント完了時にお祭りの提灯アニメーション
33. 主催者プロフィールが「お店の暖簾」風カード
34. ダッシュボードトップに「次のお祭りまであと◯日」カウントダウン
35. シーズン（春夏秋冬・お祭り）で背景や装飾が変わる

### 収束：KJ法でグループ化

| グループ | 含むアイデア | 中核アイデア |
|---|---|---|
| **G1: ダッシュボード一画面化** | 1, 3, 7, 8, 30 | 「今やるべきこと」が一目で並ぶダッシュボード |
| **G2: 視覚的な申請レビュー** | 2, 9, 12, 13, 28 | Instagram風グリッドで申請を一覧表示 |
| **G3: 信頼可視化** | 10, 15, 16 | 出店者ごとに「過去の主催者レビュー」「写真」「世界観タグ」 |
| **G4: 一斉連絡・チャット** | 17, 18, 22 | 申請者ごとのスレッドチャット＋全員一斉メッセージ |
| **G5: 自動化（書類・お金）** | 19, 20, 21, 24, 25 | OCR・入金可視化・自動集金 |
| **G6: スマホ完結** | 26, 27, 29 | PWAでホーム追加、通知あり |
| **G7: お祭りらしさの演出** | 31, 32, 33, 34, 35 | 提灯モチーフ・カウントダウン・季節感 |

### 有望案（PHASE 3 で具体化）
- 「**ダッシュボード一画面化**」(G1) — 主軸機能
- 「**写真主体の出店者プロフィール＋過去レビュー**」(G2+G3) — 差別化機能
- 「**お祭りらしさの演出**」(G7) — トーン・ブランド体験

## 3.1.B store 側ブレスト

### 解くべき課題（再掲）
1. 案件探しが散在 → 案件一覧＋マッチング
2. 主催者の雰囲気・客層判断難 → プロフィール充実
3. 申請毎にゼロから書類PR → テンプレ・書類再利用

### 発散：35案

**A. 案件発見系**
1. ホームに「今週末空いてる人にオススメ」イベント
2. 過去の出店履歴から「あなたに合いそう」AI推薦
3. エリア地図上にイベントピン
4. 「客層タグ」フィルター（ファミリー/カップル/シニア/学生）
5. 「保存」してじっくり比較できるブックマーク
6. 締切まで残り◯日のカウントダウン表示
7. 通勤路沿いのイベント自動表示
8. カレンダー連動「この日空いてる」イベントだけ表示
9. 主催者をフォローして新着通知
10. 「同じ系統の出店者が出るイベント」レコメンド

**B. 主催者の雰囲気可視化系**
11. 主催者プロフィールに「過去イベント写真」スライド
12. 過去出店者のレビュー（星＋コメント＋写真）
13. 「集客実績」グラフ（来場者数の推移）
14. 主催者の世界観タグ（ナチュラル/モダン等）
15. 主催者のInstagram自動埋め込み
16. 過去イベントの動画ダイジェスト
17. 「客単価帯」「物販向け/食品向け」絞り込み
18. 主催者ごとの「平均集客」「平均売上」を出店者間で集計

**C. 申請の楽さ系**
19. プロフィール情報から自己PR自動生成
20. 営業許可証は一度アップロードしたら使い回し
21. 申請テンプレ「定型文ライブラリ」
22. 過去申請をコピーして使える
23. 申請ボタン1タップ→AIが自己PR下書き
24. 書類はOCRで自動入力
25. 申請文字数の目安バー（少なすぎ警告）

**D. リスク・安心系**
26. 主催者の「支払いの早さ」評価
27. 「ドタキャン率」「日程変更回数」を可視化
28. 「最低保証あり」「天候保証あり」フィルター
29. キャンセル料規定をひと目で
30. 主催者からの返信スピード平均表示

**E. 楽しさ・自己表現系**
31. プロフィールに「私の世界観」コラージュ写真
32. 出店履歴に「思い出」コメントを残せる
33. 出店者同士で「次あのイベント行く？」軽い交流
34. 自分の出店履歴をお店の歴史としてストーリー化
35. 採用された瞬間にお祭り感あるお祝いアニメ

### 収束：KJ法でグループ化

| グループ | 含むアイデア | 中核アイデア |
|---|---|---|
| **G1: スマートな案件発見** | 1, 2, 5, 6, 8 | ホーム=「あなた向け」イベント＋カレンダー連動 |
| **G2: 主催者の雰囲気可視化** | 11, 12, 13, 14, 17 | 主催者プロフィール=写真＋過去レビュー＋集客実績 |
| **G3: 申請の摩擦削減** | 19, 20, 21, 22, 23 | テンプレ・書類使い回し・AI下書き |
| **G4: リスク事前回避** | 26, 27, 28, 29 | 主催者の信頼指標（支払い・キャンセル率） |
| **G5: 世界観の自己表現** | 31, 32, 34 | プロフィール=コラージュ写真＋出店履歴ストーリー |
| **G6: お祭りらしさ** | 35 | 採用時のお祝いアニメ |

### 有望案
- 「**ホーム=あなた向けイベント**」(G1+G2) — 主軸機能
- 「**プロフィール=世界観のコラージュ**」(G5) — 差別化機能
- 「**書類・テンプレ使い回し**」(G3) — 摩擦削減
