## 由来とブランド精神

> Wacca = 「輪っか（輪）」+「和（調和・日本的）」
>
> 主催者の熱意・出店者のこだわり・来場者の笑顔の3要素が重なり合って一つの「輪」が完成する。バラバラだったイベント情報を面で結び、循環を生み出すインフラ。

## システム構成

| アプリ | 役割 | URL（最新） |
|---|---|---|
| **organizer** | 主催者向けWebアプリ：イベント作成、応募審査、配置、消防届出リスト出力、請求書 | eventra-organizer.vercel.app |
| **store** | 出店者向けWebアプリ：プロフィール、応募、書類、採用通知 | eventra-store.vercel.app |
| **admin** | 運営者向けWebアプリ：審査承認、ユーザー管理、自動請求 | eventra-admin.vercel.app |

技術スタック：Next.js 16（App Router）+ React 19 + TypeScript / Tailwind v4 / Supabase

**重要：LINE Bot構想は破棄済み。3アプリすべてWebアプリ。**

## ビジネスモデル

- **主催者課金モデル**：紹介数 × イベント日数 × 主催者単価 → 自動請求
- **出店料の決済は主催者⇔出店者直接**（プラットフォーム非介在）
- **中抜き禁止条項**：Wacca経由で出会ったユーザー間の直接取引（プラットフォーム外契約）を禁止、違反時は違約金

## 信頼性設計

| 仕組み | 内容 |
|---|---|
| **反社排除** | 登録時に表明・保証、違反時即時アカウント削除 |
| **Wacca Gold Star認定** | 一定評価獲得の優良Storeに付与（ミシュラン的バッジ） |
| **公式出店ステッカー** | マッチング成立Storeに配布、来場者にも安心感を演出 |
| **承認後の連絡先開示** | 承認まで連絡先は非開示、承認時に氏名・メール・電話を開示 |
| **双方向評価制度** | 星評価＋コメント（運営と本人のみ閲覧可） |
| **通報システム** | 連絡不通・無断キャンセル・金銭トラブル等 |
| **賠償上限** | 1,000円（消費者契約法上限規定除く） |
