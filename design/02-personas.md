# 02 ペルソナ（資料準拠・抽象化版 v2）

実名は使わず、資料が示すターゲット属性で抽象化する（B方針）。
**重要要件**：「高齢の出展者・主催者でも迷わない」が明示されているため、各サイドにシニア層ペルソナを必ず含める。

---

## 主催者ペルソナ（3名）

### O1：地域祭実行委員型（シニア・デジタル弱）

```
所属：地域の祭実行委員会（自治会・商工会・観光協会）
年代：60〜70代、男女問わず
役職：実行委員長または運営事務局長
イベント頻度：年1〜4回（地域の祭・盆踊り・収穫祭）
規模：出店者15〜50店舗
予算：自治体補助＋協賛金、有料サービスは月数千円が上限

【デジタル習熟】
★☆☆☆☆
- スマホは LINE/通話/写真撮影 中心
- PCは Excel と Word を「教えてもらいながら」使う
- メールは確認するが、新規作成は苦手

【現状の運営方法】
- 出店者は「去年も出てくれた人」中心
- 新規開拓は「知り合いの紹介」のみ
- 応募は電話・FAX・LINEで散在
- 書類は紙ファイル
- 入金は銀行通帳をめくって確認

【一番困っていること】
1. 若い出店者を呼びたいが繋がりがない
2. 申請書類が紙バラバラで管理しきれない
3. 消防届出の書類作成が毎年苦痛
4. 後継者がデジタル化を望むが何から始めればいいか分からない

【Waccaに期待すること】
- とにかくシンプル、迷わない
- 大きいボタン、最小限の入力
- 紙の運用と並行できる猶予
- 電話サポートがあると安心
```

### O2：個人主催型（30〜40代・デジタル中強）

```
所属：個人 or 任意団体（マルシェ運営・地域おこし・カフェ集会等）
年代：30〜40代、女性が比較的多い
立場：会社員の副業 or フリーランス
イベント頻度：月1〜年12回（マルシェ・クラフト市・地域おこし）
規模：出店者10〜40店舗

【デジタル習熟】
★★★★☆
- スマホ・PC両方使いこなす
- Notion / Googleフォーム / Instagram は日常
- デザイン感度が高い、業務システム的UIは拒絶
- LINEと同等以上の操作感を要求

【現状の運営方法】
- Instagram で集客・出店者募集
- Googleフォームで応募受付
- Notionで応募者管理
- 個別メールでやり取り
- 散在の合計時間が地味に多い

【一番困っていること】
1. 応募管理ツールが散在
2. 出店者の「世界観」が事前に判断しづらい
3. 副業で時間がない、スマホ完結したい
4. お金のやり取りが面倒

【Waccaに期待すること】
- スマホで完結
- 写真で「世界観」が伝わるプロフィール
- LINEより少し整った操作感
- ダサくないUI（自分の世界観に合う）
```

### O3：商業施設・企業販促型（30〜50代・デジタル強）

```
所属：商業施設の販促部 / 自治体の地域おこし部署 / 企業の販促・広報
年代：30〜50代
役職：販促担当・課長クラス
イベント頻度：月2〜3回（駐車場催事・季節フェス・キッチンカー定期）
規模：出店者5〜20店舗

【デジタル習熟】
★★★★★
- 業務システム慣れ
- レポート作成・KPI管理が日常
- コンプライアンス意識高、PDF証跡必須

【現状の運営方法】
- モビマル等の既存サービスを併用
- 上層部承認のため証跡をPDFで残す
- レポート作成のため出店者・売上データ集計

【一番困っていること】
1. 既存サービスが高額・規模に合わない
2. レポート用データ集計に手間
3. 上層部承認のための証跡管理が煩雑
4. キッチンカー以外も巻き込みたいが対応サービスが少ない

【Waccaに期待すること】
- 規模相応の価格
- PDF証跡（請求書・配置図・規約）
- レポート用CSVエクスポート
- マルチカテゴリ対応
```

## 出店者ペルソナ（3名）

### S1：専業キッチンカー型（50〜60代・デジタル中）

```
業種：専業キッチンカーオーナー（メニュー1〜2品特化）
年代：50〜60代、男性が比較的多い
規模：個人事業主 or 2〜3人体制、年商600〜1500万円
出店頻度：週末中心、月4〜10回

【デジタル習熟】
★★☆☆☆
- スマホは LINE/Google Maps/Instagram 程度
- PCは申請書作成のみ
- 申請フォーム入力は「家族に手伝ってもらう」ことも

【現状の出店先探し】
- 業界の知人ネットワーク（LINEグループ）
- 過去出店イベントのリピート
- たまにInstagram DMで営業

【一番困っていること】
1. 案件探しに毎週時間取られる
2. 主催者の信頼性・支払い実績が分からない
3. 営業許可証を毎回提出する手間
4. 火気・発電機の届出書類が主催者ごとにフォーマット違って混乱

【Waccaに期待すること】
- 案件一覧で楽に探せる
- 書類は一度上げたら使い回し
- 大きなボタン、シンプル操作
- 主催者の評判が分かる
```

### S2：副業出店型（30〜40代・デジタル強）

```
業種：副業（自家製スイーツ／クラフト／ハンドメイド／物販）
年代：30〜40代、女性が比較的多い
規模：個人、月商10〜30万円
本業：会社員 or フリーランス
出店頻度：月1〜4回（土日中心）

【デジタル習熟】
★★★★★
- Instagram/Notion/Canva 使いこなす
- 業務システムUIは苦手
- スマホ完結志向

【現状の出店先探し】
- Instagram のハッシュタグ検索
- 副業仲間のLINEオープンチャット
- 主催者のアカウントを5往復見て判断

【一番困っていること】
1. 平日時間ゼロ、スマホ完結必須
2. 主催者の世界観・客層が事前に判断難
3. 申請文を毎回ゼロから書く
4. 自分の世界観をプロフィールで表現したい

【Waccaに期待すること】
- スマホで完結
- 主催者プロフィール（写真・客層・過去レビュー）
- 申請フォーム自動入力＋書類使い回し
- プロフィールで自己表現できる写真ギャラリー
```

### S3：農家・生産者型（50〜70代・デジタル弱）

```
業種：農家・果樹・加工品生産者
年代：50〜70代
規模：個人 or 家族経営
出店頻度：直販目的、収穫期に集中

【デジタル習熟】
★☆☆☆☆
- スマホは LINE/通話のみ
- PCは年に数回
- 「カタカナだらけのアプリ」は拒絶感

【現状の出店先探し】
- 農協・地域団体経由
- 過去出店マルシェのリピート
- 紹介ベース

【一番困っていること】
1. デジタル化の波に取り残されている自覚
2. 「もっと若い客層にも届けたい」がチャネルがない
3. 申請フォームの「カタカナ用語」が分からない
4. 写真撮影・SNSが苦手

【Waccaに期待すること】
- 日本語で・大きな字で・最小限の入力
- 申請は「3画面で終わる」シンプルさ
- 電話サポート or 主催者からのフォロー
- 「あなたの農産物に合うイベント」を提案してくれる
```

## 設計原則への落とし込み

ペルソナの広いスペクトラム（デジタル弱〜強、シニア〜若手）を**同じUIで満たす**ために、Waccaは以下を守る：

| 原則 | 理由 |
|---|---|
| **大きなボタン・最小限入力** | O1/S1/S3（シニア・デジタル弱）が脱落しないため |
| **写真主体プロフィール** | O2/S2（デザイン感度高）が「世界観」で判断できるため |
| **PDF証跡（請求書・配置・規約）** | O3（コンプライアンス重視）に対応 |
| **日本語・カタカナ最小化** | S3（農家・シニア）が理解できるため |
| **電話/メールサポート併設** | O1/S3が安心して使えるため |
| **モバイルフル機能・PWA対応** | O2/S2/S1（外出先・スキマ時間）対応 |
| **書類使い回し（一度上げたら再利用）** | S1/S2/S3 共通の摩擦削減 |

## メインペルソナの優先順位

ローンチ時に**最初に刺さるべき層**を以下に設定：

| 優先 | ペルソナ | 理由 |
|---|---|---|
| 1位 | **O2 個人主催型** | デジタル習熟高×現状代替（Notion+Instagram+LINE）の散在が深刻×新規開拓も望む |
| 1位 | **S2 副業出店型** | O2と相性最良。Wacca的トーンが最も刺さる |
| 2位 | **O3 商業施設・自治体** | 安定収益源（高単価が見込める）。証跡・レポート機能で差別化 |
| 2位 | **S1 専業キッチンカー** | 出店頻度高く、案件探し時間削減効果が大きい |
| 3位 | **O1 祭実行委** | デジタル化伴走が必要だが、Waccaのインフラ性を支える層 |
| 3位 | **S3 農家・生産者** | スコープ拡張の象徴、シニア対応力の証 |

**v1 ローンチ時**：1位の O2×S2 を主軸として設計。2位の証跡・大ボタン要件は最初から内蔵し、3位の電話サポート併設で広く対応。
