### F4. イベント作成フォーム（主催者）

**4ステップ構成**。資料「イベント作成フォーム 画面・要件定義書」準拠。

#### Step 1: イベントの魅力と基本情報

| 項目 | 必須 | 入力種別 |
|---|---|---|
| イベント名 | ◎ | テキスト |
| ジャンル | ◎ | 単一選択（13カテゴリ） |
| イベント説明・想い | ◎ | テキストエリア |
| **ターゲット層** | ◎ | 複数選択（ファミリー/学生/20-30代/高齢者 等） |
| **予想来場者数** | ◎ | 数値入力 |
| メイン画像 | ◎ | 画像アップロード |
| 開催日 | ◎ | 日付（開始＋終了） |
| 開始/終了時間 | ◎ | 時間選択 |
| 日別スケジュール | 任意 | 動的リスト |
| **延期設定** | ◎ | ラジオ＋日付（延期なし／予備日あり） |
| 会場名 | ◎ | テキスト |
| 住所 | ◎ | 郵便番号API＋テキスト |
| **会場インフラ提供** | ◎ | ラジオ（電源提供：あり/なし、水道：あり/なし） |
| **禁止・制限事項** | ◎ | 複数選択（火気厳禁／アルコールNG／匂い強NG 等） |

#### Step 2: 募集枠・規約・運営

| 項目 | 必須 | 入力種別 |
|---|---|---|
| 出店数（総枠） | ◎ | 数値 |
| 出店料 | ◎ | 数値／テキスト（歩合制等の柔軟入力） |
| **カテゴリ別募集枠** | 任意 | 動的リスト（主食○枠／デザート○枠 等） |
| 日別募集条件 | 任意 | 動的リスト |
| **他出店者の公開設定** | ◎ | ラジオ（全公開／カテゴリのみ／非公開） |
| 募集締切 | ◎ | 日付 |
| 主催者名 | ◎ | テキスト |
| 連絡先 | ◎ | メール＋電話 |
| 各種規約 | ◎ | テキストエリア（出店資格／キャンセル／個人情報） |

#### Step 3: 出店者への質問項目設定（プリセット）

| カテゴリ | 項目 | 形式 |
|---|---|---|
| **基本** | 出店形態（テント／キッチンカー／相談可） | 単一選択 |
|  | 提供カテゴリ（主食／軽食／デザート／ノンアル／アルコール） | 複数選択 |
|  | メニュー詳細・販売予定数・価格帯 | テキストエリア |
|  | アレルギー表示の有無 | 単一選択 |
| **安全・インフラ（構造化）** | 火気使用機材 | 複数選択（ガスコンロ／カセット／炭火／ガスフライヤー／IH 等） |
|  | 発電機の種別 | 単一選択（持参なし／ガソリン／灯油／ガス／電動バッテリー） |
|  | 消火器の有無・有効期限 | ラジオ＋日付 |
| **必須書類** | 営業許可証＋許可番号＋自治体名＋有効期限 | ファイル＋メタ |
|  | 食品衛生責任者証 | ファイル |
|  | 車検証（KC選択時のみ） | ファイル |
|  | PL保険証書 | ファイル |
| **カスタム質問** | 主催者自由追加（テキスト or ファイル） | 動的追加 |

#### Step 4: 確認画面

- 全入力内容のプレビュー
- 「公開する」or「下書き保存」ボタン

## 横断機能要件

### シニア対応（O1/S1/S3向け）

- 文字サイズ 18px ベース（設定で20pxまで拡大可）
- タッチターゲット 最小 56px
- カタカナ用語の言い換え（「アップロード」→「ファイル送る」等）
- 入力項目最小化（オンボーディング 7項目以内）
- ガイド常設・電話サポート番号表示
- エラー文の平易化

### モバイル対応（O2/S2向け）

- PWA対応（ホーム画面追加可、プッシュ通知）
- スマホでフル機能（PC前提のUIなし）
- レスポンシブ（DESIGN.md準拠：Mobile/Tablet/Desktop）

### 写真主体UI（O2/S2向け）

- プロフィール画面は写真ファースト
- 応募一覧はInstagram風グリッド
- 主催者プロフィールに過去イベント写真スライド

### 証跡対応（O3向け）

- PDF出力（請求書／配置／規約／採用通知書）
- CSVエクスポート（応募者リスト等）

## hallmark フェーズで先にデザインすべき代表画面

優先順位順：

1. **organizer ダッシュボード** — 主催者の現在地・「やるべきこと」一画面集約
2. **organizer 応募一覧（写真グリッド）** — 審査UXの中核
3. **store ホーム** — 出店者の「あなた向け」レコメンド体験
4. **store プロフィール（写真ギャラリー）** — 出店者の世界観表現
5. **organizer イベント作成 Step1** — 構造化入力（ジャンル／ターゲット／禁止事項）の代表

これら5枚で：
- Navy×Orange×Greenトークンが確定
- 写真主体UIのパターン確立
- シニア対応の大ボタン・大文字パターン確立
- 構造化入力（選択式）のパターン確立
